# 生成的文件格式详解

## feature_list.json

### 完整结构
```json
{
  "project": "my-app",
  "tech_stack": ["React", "Hono", "Drizzle"],
  "created": "2025-12-31",
  "total_features": 50,
  "completed_features": 0,
  "current_session": 1,
  "features": [
    {
      "id": 1,
      "category": "core",
      "description": "用户可以注册账号",
      "steps": [
        "访问注册页面",
        "填写用户名、邮箱、密码",
        "点击注册按钮",
        "验证收到欢迎邮件"
      ],
      "passes": false,
      "priority": "high",
      "dependencies": [],
      "estimated_time": "2h",
      "notes": ""
    }
  ]
}
```

### 字段说明

#### 特性字段
- `id`: 唯一标识符
- `category`: 分类（core, ui, api, data, test, optimization）
- `description`: 特性描述（用户视角）
- `steps`: 验收步骤（如何测试）
- `passes`: 是否完成（boolean）
- `priority`: 优先级（high, medium, low）
- `dependencies`: 依赖的特性 ID 列表
- `estimated_time`: 预估时间
- `notes`: 备注信息

#### 不可修改字段
✅ 可修改：`passes`, `notes`
❌ 不可修改：`description`, `steps`, `dependencies`（保持追踪完整性）

## config.json

### 完整结构
```json
{
  "project_name": "my-app",
  "tech_stack": ["React", "Next.js", "Hono", "Drizzle"],
  "mode": "long-running",
  "created": "2025-12-31T22:00:00Z",
  "quality_rules": {
    "max_function_lines": 30,
    "max_file_lines": 400,
    "max_pr_files": 8,
    "max_single_change_lines": 150
  },
  "test_commands": {
    "smoke": "npm run test:quick",
    "full": "npm test",
    "e2e": "npm run test:e2e"
  },
  "file_limits": {
    "progress_txt_lines": 2000,
    "feature_list_max_features": 500,
    "archive_after_days": 30
  }
}
```

### 可自定义配置

#### quality_rules
项目的质量标准：
- `max_function_lines`: 单个函数最大行数
- `max_file_lines`: 单个文件最大行数
- `max_pr_files`: 单次 PR 最大文件数
- `max_single_change_lines`: 单次修改最大行数

#### test_commands
测试命令配置：
- `smoke`: 快速冒烟测试
- `full`: 完整测试套件
- `e2e`: 端到端测试

#### file_limits
文件大小限制和归档策略：
- `progress_txt_lines`: progress.txt 行数限制
- `feature_list_max_features`: feature_list.json 特性数限制
- `archive_after_days`: 归档时间（天）

## init.sh

### Bun 项目示例
```bash
#!/bin/bash
# Environment initialization script
# Auto-generated by project-initializer

echo "🚀 Starting development environment..."

# Install dependencies
if [ -f "bun.lockb" ]; then
  echo "📦 Installing dependencies with Bun..."
  bun install
fi

# Start dev server
echo "🔧 Starting development server..."
bun run dev &

echo "✅ Environment ready!"
```

### npm 项目示例
```bash
#!/bin/bash
# Environment initialization script

echo "🚀 Starting development environment..."

# Install dependencies
if [ -f "package-lock.json" ]; then
  echo "📦 Installing dependencies with npm..."
  npm install
fi

# Start dev server
echo "🔧 Starting development server..."
npm run dev &

echo "✅ Environment ready!"
```

### 自定义脚本
可以手动编辑 init.sh 添加：
- 数据库启动
- 环境变量检查
- 依赖服务启动
- 健康检查

## 文件管理最佳实践

### 1. feature_list.json
- 定期备份：`cp feature_list.json feature_list.json.backup`
- 使用 Git 追踪
- 谨慎修改（只改 passes 和 notes）

### 2. progress.txt
- 超过 2000 行时归档
- 使用 `scripts/archive-progress.sh`
- 保留最近 1000 行

### 3. config.json
- 根据项目需求调整质量规则
- 测试命令与项目实际命令一致
- 文件限制根据项目规模调整
