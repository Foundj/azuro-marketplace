# Analysis Frameworks Reference

> Structured thinking frameworks for thinking-engine

## Task Analysis (5-Step)

1. **Understand Task**: Type, verbs, domain
2. **Analyze Context**: Stack, structure, dependencies
3. **Evaluate Complexity**: Score 1-10, risks
4. **Select Strategy**: Agents, workflow, time
5. **Validate Approach**: Feasibility, issues, alternatives

## Problem Solving (5-Step)

1. **Define Problem**: Symptoms, impact, reproduction
2. **Root Cause**: Hypotheses, verification, data
3. **Design Solution**: Options, pros/cons, recommendation
4. **Implementation Plan**: Files, tests, rollback
5. **Verification**: Results, edge cases, monitoring

## Architecture Design (6-Step)

1. **Requirements**: Functional, non-functional, constraints
2. **Decomposition**: Modules, boundaries, responsibilities
3. **Technology**: Candidates, criteria, selection
4. **Interfaces**: APIs, data flow, protocols
5. **Performance**: Bottlenecks, scaling, capacity
6. **Security**: Threats, protection, recovery
