本模板定义版本化计划文档的标准格式。plan.md 是设计文档（WHY + WHAT + HOW），不含任何复选框。

---

name: {{NAME}}
date: {{DATE}}
baseline: {{BASELINE}}
status: draft
discussion_source: {{DISCUSSION_SOURCE}}
---

## 模板使用说明

### 占位符

**共享占位符**（plan-template 和 task-template 共用）：

| 占位符 | 来源 | 说明 |
|--------|------|------|
| `{{VERSION}}` | 版本号决策规则 | 如 1.0, 2.0 |
| `{{NAME}}` | 讨论标题/需求名称 | 人类可读名称 |
| `{{DATE}}` | 当前日期 | YYYY-MM-DD |
| `{{BASELINE}}` | 前一版本号 | 如 v0, v1.0 |
| `{{DISCUSSION_SOURCE}}` | 来源文件路径 | 讨论来源填 `docs/discussions/<topic>/discussion.md`；需求来源填 proposal 路径；直接创建填 "用户直接对话" |
| `{{SPRINT_1_NAME}}` | Sprint 名称 | 如「基础架构」 |
| `{{SPRINT_2_NAME}}` | Sprint 名称 | 第二个 Sprint |
| `{{STEP_NAME}}` | 步骤名称 | Sprint 内的具体步骤 |
| `{{FILE_PATH}}` | 文件路径 | 涉及修改的文件路径 |

### 关键约束

1. **禁止复选框** — plan.md 中不得出现 `- [ ]` 或 `- [x]`，所有进度追踪在 task.md
2. **编号散文** — 验收标准和开放问题使用编号列表
3. **ADR 溯源** — 每个架构决策记录必须注明来源讨论轮次和角色
4. **信心度来源** — 优先使用 requirement-analyzer 的评估数据填充
