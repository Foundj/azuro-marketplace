# Subagent Reporting Reference

## Report Structure
Subagents must report their work using the following sections:

1. **What was implemented**: Clear description of changes.
2. **Test results**: Output of the verification tests.
3. **Files changed**: List of modified file paths.
4. **Self-review checklist**: Verification of TDD and standards.
5. **Concerns**: Any ambiguities or potential issues discovered.

## Handoff Protocol
The lead agent must:
1. Verify Stage 1: Spec Compliance.
2. Verify Stage 2: Code Quality.
3. Mark task as [x] in tasks.md only after both pass.
