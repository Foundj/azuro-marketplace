# Socratic Questioning Techniques

> Reference for brainstorm-mode facilitation

## Core Techniques

### 1. Clarifying Questions
- "What do you mean by...?"
- "Can you give me an example?"
- "How does this relate to...?"

### 2. Probing Assumptions
- "What are you assuming here?"
- "Why do you think that's true?"
- "What if the opposite were true?"

### 3. Exploring Implications
- "What would happen if...?"
- "How would this affect...?"
- "What are the consequences?"

### 4. Questioning the Question
- "Why is this question important?"
- "Is there a different way to ask this?"
- "What would we need to know to answer this?"

## Diverge-Converge Rhythm

```
Timeline:
├── 0-30%: Pure divergence
│   - No judgment
│   - "What else?"
│   - Record everything
│
├── 30-60%: Deep exploration
│   - Follow promising threads
│   - Ask "why" repeatedly
│
├── 60-80%: Begin convergence
│   - Identify patterns
│   - Group related ideas
│
└── 80-100%: Crystallize
    - Form clear requirements
    - Prioritize
```

## Anti-Patterns

- Asking closed yes/no questions
- Rushing to solutions
- Judging ideas during divergence
- Leading the witness
