## 🔄 OODA循环核心理念

### OODA Loop定义
- **Observe** (观察) - 理解当前状态
- **Orient** (定位) - 分析上下文和选项  
- **Decide** (决策) - 选择最简单有效的行动
- **Act** (行动) - 执行并快速验证

### 核心原则
1. **速度优于完美** - 快速迭代胜过一次性完美
2. **验证优于假设** - 实际测试胜过理论分析
3. **简单优于复杂** - 简单方案优先考虑
4. **反馈优于计划** - 基于反馈调整方向

### 3次尝试规则
```typescript
interface ThreeStrikeRule {
  maxAttempts: 3,
  
  strikeOne: {
    action: "继续尝试当前方向",
    reflection: "分析失败原因，微调方法"
  },
  
  strikeTwo: {
    action: "重新审视问题定义", 
    reflection: "可能是理解错误，换个角度"
  },
  
  strikeThree: {
    action: "停止并寻求帮助或换方法",
    reflection: "可能是XY问题，需要重新思考"
  }
}

function handleFailure(attempt: number, error: Error) {
  if (attempt >= 3) {
    return {
      action: "STOP",
      message: "3次尝试均失败，需要重新审视问题本质",
      suggestions: [
        "是否在解决错误的问题？(XY Problem)",
        "是否需要更多背景信息？",
        "是否需要简化问题？",
        "是否需要寻求外部帮助？"
      ]
    }
  }
  
  return { action: "RETRY", attempt: attempt + 1 }
}
```

## 📊 OODA循环执行流程

### Observe阶段 (5分钟)
```markdown
## 🔍 观察检查清单
- [ ] **当前状态评估**: 代码/系统/需求现状如何？
- [ ] **问题明确定义**: 要解决的具体问题是什么？
- [ ] **约束条件识别**: 时间/技术/资源限制？
- [ ] **成功标准设定**: 什么算作成功？
- [ ] **上下文范围确定**: 需要哪些最小上下文？

### 关键输出
- 问题的清晰定义
- 当前状态快照
- 本次迭代的具体目标
```

### Orient阶段 (10分钟)
```markdown
## 🧭 定位分析框架
- [ ] **方案生成**: 至少3种不同解决方案
- [ ] **复杂度评估**: 每个方案的实现复杂度 (1-10)
- [ ] **风险评估**: 每个方案的潜在风险
- [ ] **时间估算**: 40分钟内能完成哪个方案？
- [ ] **验证计划**: 如何快速验证结果？

### 方案选择标准
1. **可以在40分钟内完成**
2. **复杂度≤5分**
3. **风险可控**
4. **容易验证**
5. **容易回滚**
```

### Decide阶段 (5分钟)
```markdown
## ⚡ 决策检查清单
- [ ] **选定方案**: 明确选择哪个方案，为什么？
- [ ] **行动计划**: 具体的执行步骤 (≤5步)
- [ ] **验证标准**: 如何知道成功/失败？
- [ ] **退出条件**: 什么时候停止并重新评估？
- [ ] **回滚计划**: 失败时如何快速恢复？

### 决策记录模板
**选择方案**: [方案名称]
**理由**: [选择此方案的原因]
**预期结果**: [期望达到的效果]
**验证方法**: [如何验证结果]
**风险控制**: [如何管理风险]
```

### Act阶段 (40分钟)
```markdown
## 🏃 行动执行规范
- [ ] **设置计时器**: 严格40分钟限制
- [ ] **最小化变更**: 每次变更≤50行代码
- [ ] **频繁验证**: 每15分钟验证一次进度
- [ ] **记录问题**: 遇到的问题和解决方案
- [ ] **准备演示**: 能够展示具体结果

### 执行监控
- **15分钟检查点**: 进度是否正常？
- **30分钟检查点**: 能否按时完成？
- **40分钟硬停止**: 无论是否完成，必须停止

### 结果验证
- 代码能否运行？
- 解决了预期问题吗？
- 有没有引入新问题？
- 可以向他人解释吗？
```
